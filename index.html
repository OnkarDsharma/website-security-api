What we check

Every scan runs these 10 checks in parallel and explains each finding in plain language.

01

Security headers

HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy.

02

SSL / TLS

Certificate expiry, trust issues, outdated TLS protocol versions.

03

Exposed sensitive files

.env, .git/config, AWS credentials, config backups.

04

CMS version

Detects WordPress, Joomla, Drupal and flags outdated versions.

05

Server info leakage

Headers that reveal exact software versions to attackers.

06

Email spoofing protection

Checks for SPF and DMARC DNS records.

07

CORS configuration

Flags dangerous wide-open + credentialed combinations.

08

Cookie security

Missing Secure, HttpOnly, or SameSite attributes.

09

Mixed content

HTTP resources quietly loaded on an HTTPS page.

10

Open redirects

Unvalidated redirect parameters, a common phishing vector.

A note on accuracy. This is an automated, lightweight scanner — not a substitute for a full penetration test or professional security audit. CMS checks use a simple version heuristic, not a CVE database. Open redirect detection tests common parameter names, not an exhaustive list. If a check can't be completed, the report says so explicitly rather than showing a false clean result.
